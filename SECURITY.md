# Security Policy

## Reporting a Vulnerability

If you discover a security or privacy vulnerability in the Capture-Manifest specification, JSON schemas, or validation/creation tooling, please report it privately to **[security@fusionlayer.app](mailto:security@fusionlayer.app)** rather than opening a public issue.

We acknowledge reports within 48 hours and aim to publish a coordinated fix and advisory within 14 days of verification.
